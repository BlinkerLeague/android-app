깜빡이리그 · 정차(P) 화면 게임 UI/UX 제안

"운행 = 한 경기, 회전 = 한 플레이, 깜빡이 = 득점"이라는 지금의 경기 비유를 화면 전체로 끌어올리는 안입니다. 데이터와 화면 흐름은 그대로 두고 표현(레이아웃 · 색 · 모션 · 문구)만 바꿉니다. 모든 화면은 기어 P · 정차일 때만 보이며(DrivingGuard), 주행 중 규칙은 바꾸지 않습니다.

P 전용 정차 화면에서만 보임   신규 요소 지금 화면에 없는 것   안전 장치 모션 · 소리 제한  ·  각 화면 제목 옆 모션 다시 보기로 등장 애니메이션을 볼 수 있습니다. 화면 크기는 앱 목업 기준인 1280×720입니다.

디자인 원칙

  • 경기 비유를 일관되게: 운행 = 경기, 회전 = 플레이, 깜빡이 켬 = 득점(초록), 안 켬 = 실점(주황), 평점 = 등급 도장, 포인트 = 상금, 퀘스트 = 오늘의 도전, 연속 달성 = 연승.
  • 빈 공간을 무대로: 지금 화면은 큰 패널에 글자 몇 줄만 있습니다. 가장 중요한 숫자 하나(등급 · 연승 · 진행도)를 크게, 시각 장치(도장 · 링 · 불꽃 · 트로피)와 함께 보여줍니다.
  • 보상은 순서대로 터뜨리기: 결과 화면은 0.3초 간격으로 스코어보드 → 스탯 → 등급 도장 → 상금 → 퀘스트 배너 순서로 등장합니다. "결과를 받는" 느낌을 만듭니다.
  • 차량 화면 기준 유지: 다크 테마, 글자 18sp 이상, 터치 영역 64dp 이상, 문장은 한 줄. 강조색은 의미가 있을 때만 씁니다.
