## 9. NaviHelper 이벤트 콜백 조사 요청

- **로거**: `NaviHelperEventListener` 콜백 26개를 모두 Logcat `NaviTest`로 기록했습니다.

- **한계**: 에뮬레이터 내비가 GPS를 따라 진행하지 않아, 안내 중 갱신 주기는 측정하지 못했습니다.
- **환경 조치**: 에뮬레이터 Wi-Fi를 연결했고, Virtual Console은 세션 신호가 필요하다는 것을 확인했습니다.

## 10. 차량 신호 백그라운드·속도 조사 요청

- **백그라운드 수신**: 일반 백그라운드는 약 10초 뒤 얼어서 콜백이 전부 누락됐고, 다시 열면 프로세스가 종료됐습니다. 포그라운드 서비스에서는 모두 즉시 왔습니다.
- **깜빡이**: OFF/RIGHT/LEFT 세 값뿐이고 비상등은 없습니다.
- **조향각**: 단위는 도(°)입니다. 콘솔에서 오른쪽(+)으로 꺾으면 SDK에는 음수로 옵니다. 약 3초마다 같은 값이 다시 옵니다.
- **속도**: CarProperty `PERF_VEHICLE_SPEED`로 읽히고, 단위는 m/s, 약 10Hz입니다. `CAR_SPEED` 런타임 권한이 필요하고, AAOS라 사용자별로 허용해야 합니다.
- **기어**: Vehicle SDK와 CarProperty 둘 다 읽힙니다.
- **결과**: PR #14, `docs/spikes/vehicle-background-speed.md`

## 11. 같은 문서에 이어서 조사 + 코드 변경 요청

- **오도미터**:
  - 트립 거리·시간 API는 에뮬레이터에서 지원하지 않습니다.
  - 오도미터는 콘솔이 직접 쓰는 값이라 속도를 줘도 늘지 않습니다.
  - 속도 적분은 2km 구간에서 2.001km로 정확했습니다. → 운행 거리는 속도 적분으로 계산합니다.
- **비상등**: Light 도메인에 API가 없고, Safety 경고등은 빈 목록이라 감지할 수 없습니다.
- **포그라운드 서비스 시작 경로**:
  - 앱이 보일 때, 화면에서 막 내려간 직후, 부팅(`BOOT_COMPLETED`), 앱 재설치는 시작이 허용됐습니다.
  - 얼어 있는 백그라운드에서는 거부됐습니다.
  - 시동을 다시 켤 때의 경로는 미확인입니다.
  - 서비스 type은 `specialUse`입니다.
- **코드 변경**:
  - `steeringRightPositive` 기본값을 `false`로 바꿨습니다.
  - 비상등 규칙에 "TurnSignal로 감지 불가"를 주석과 문서로 남겼습니다.
  - 서버 요청 문서에 7번 항목을 추가했습니다.
- **결과**: PR #14에 추가

## 12. 위치 수신 조사 요청

- **SDK와 권한**: Pleos FusedLocation SDK 1.1.3을 추가했고, `isSupported()`는 true입니다. 권한은 dangerous라 런타임 허용이 필요합니다.
- **위치 추적**: 주입 좌표를 1초마다 따라왔습니다(지연 12ms). 고도도 반영되고, heading은 항상 0이며 속도·주소 필드는 없습니다.
- **앱 상태별 결과**:
  - 직전에 쓴 앱이면 얼지 않지만 지연이 548ms로 늘었습니다.
  - 다른 앱을 거치면 얼어서 0회였습니다.
  - 포그라운드 서비스에서는 정상이었습니다.
- **근접 알림**: 원형(중심+반경)이고, 경계를 넘은 뒤 약 15ms에 진입·이탈이 왔습니다.
- **NaviHelper 비교**: 내비 위치는 고정값이라, 위치 출처는 FusedLocation SDK로 정했습니다.
- **결과**: PR #16, `docs/spikes/fused-location.md`
